## Result

The accepted normalized Meshy-native canary model and its normalization report
were copied into each real-character candidate as two immutable source
contributions. Each candidate now has one six-root compound lineage: its ZIP,
character FBX, Walking-withSkin FBX, texture PNG, canary GLB, and canary report.

The processor retained the real character mesh, material, exact texture,
24-joint native hierarchy and inverse-bind relationship. It applies the
Godot-facing corridor's explicit deterministic top-four skin policy rather
than claiming exact preservation of every source influence: influences are
ordered by descending weight with a bone-name tie-break, four are retained,
and those four are renormalized. It transferred all ten canary actions through
parent-relative native rest-space deltas, preserved their source timing, and
reconciled XY root baseline and ground height against the actual target mesh.
There is no Mixamo retarget, bone-index graft, provider call, or character
migration.

## Runtime-readiness gaps

These packages are deliberately **not Vandrel-ready**. The smallest missing
native provider motions are:

- one neutral standing Idle loop;
- one death/fall clip that settles into a stable held final pose.

Unrelated collection or stylized-walk actions must not substitute for those
gaps. Eating still needs a cleaner loop with visible chewing if the current
hand-to-mouth clip is insufficient in gameplay, and butchering still needs a
credible repeated cutting/dressing loop if the current ground-work reach is
insufficient.
